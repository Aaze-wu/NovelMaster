# -------------------------- 可选依赖（非必需） --------------------------
# 以下依赖不安装也能正常运行，缺失时对应格式会自动降级或禁用。
#
# mobi>=0.4.1
#     MOBI / AZW / AZW3 / PRC 的增强解析库。
#     注意：该库采用 GPL-3.0-only 许可，与本项目的 MIT 许可不兼容，
#     因此不列为必需依赖。未安装时，程序使用内置的
#     PalmDB + PalmDOC 解析器读取上述格式，功能基本一致。
#
#     如确需安装（请自行评估许可影响）：
#     pip install mobi
#
# pywin32>=306
#     朗读功能的增强依赖。装上后朗读会走 sapi-com 后端（直接用 SAPI.SpVoice
#     驱动语音），能多枚举出系统 OneCore 语音库里的音色，例如中文的
#     Kangkang（男声）与 Yaoyao（女声）。未安装时自动回落到
#     PyQt5.QtTextToSpeech，朗读功能一样齐全，只是可选音色少一些。
#     官方发行版已随包附带，源码运行想体验更多音色时再装：
#     pip install pywin32
#
# sherpa-onnx>=1.13.8
#     朗读的「离线神经音色」依赖（Apache-2.0）。装上后可以用
#     Piper（超文 / 小雅 / 花颜）与 Kokoro（103 个音色，中英日等多语言）
#     这些神经网络音色，不联网、免费、音质比系统语音好很多。
#     注意：语音模型**不在**依赖里，第一次使用时在程序内
#     「朗读 → 音色管理…」里按需下载（Piper 小模型 13 MB，Kokoro 140 MB），
#     下完之后存在 %APPDATA%\NovelMaster\tts_models\ 下，可随时删除。
#     未安装时朗读自动回落系统语音，其余功能不受影响。
#     官方发行版已随包附带，源码运行想体验神经音色时再装：
#     pip install sherpa-onnx
#
# edge-tts>=7.2.8
#     朗读的「在线音色」依赖（MIT）。装上后可以挑选微软 Azure 的
#     300 多个在线音色（中文 6 个，如 Xiaoxiao / Yunxi / Xiaoyi）。
#     音质是三者里最好的，但需要联网，且音频是 MP3（用 QtMultimedia 播放）。
#     未安装时朗读自动回落系统语音；装了但断网时会明确提示合成失败。
#     pip install edge-tts
#
# winrt-runtime / winrt-Windows.Media 等（pywinrt 投影，v1.3.9 起）
#     「全局媒体键」依赖（MIT）。装上后设置里可以打开「媒体键控制朗读」：
#     键盘上的播放 / 暂停、上一句 / 下一句直接控制朗读，
#     任务栏的媒体浮层（SMTC）上还会显示书名与当前章节。
#     需要一组包，一次装齐（均为纯官方投影，cp3xx 轮子）：
#     pip install winrt-runtime winrt-Windows.Foundation \
#                 winrt-Windows.Foundation.Collections \
#                 winrt-Windows.Media \
#                 winrt-Windows.Media.Core \
#                 winrt-Windows.Media.Control \
#                 winrt-Windows.Media.Playback \
#                 winrt-Windows.Storage \
#                 winrt-Windows.Storage.Streams
#     未安装时设置里的媒体键开关会自动置灰（点了会弹说明），其余功能不受影响。
#     注意：媒体键靠一个静音音源撑住会话，所以音量合成器里会多一条
#     NovelMaster 的静音条目，这是预期现象。
#
#     想省事就一次装齐：
#     pip install sherpa-onnx edge-tts
#
# pypinyin>=0.55.0
#     朗读读音纠正的「自动推断」依赖（MIT，轮子约 840 KB）。
#     所有朗读引擎都会把一部分多音字读错（银行读成 xíng、重新读成 zhòng、
#     单薄读成 báo……）。程序的做法是把读错的字换成读音相同、而且只有这一个
#     读音的常用字（银行 → 银航），四个引擎（sherpa / sapi-com / sapi / edge）
#     一视同仁，不用给谁拼 SSML。
#     其中「用户词典」和「内置规则」两层不依赖任何第三方库；只有第三层
#     「自动推断」需要 pypinyin 逐字注音。没装时自动层整体关闭，前两层照常
#     工作，朗读功能不受影响。
#     pip install pypinyin
